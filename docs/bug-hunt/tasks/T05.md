## 1. Lingkup yang Diperiksa dan Tidak Sempat Diperiksa

### Lingkup yang Diperiksa
1. `src/App.tsx`: Manajemen state Notch, ref sinkronisasi, listener Tauri dan DOM (`pointerdown`, `pointermove`, `keydown`, `onMouseEnter`, `onMouseLeave`, `onDragDropEvent`), timer animasi keluar dan tutup (`isClosingRef`, `closeGraceUntilRef`, `isSwitchingTabRef`, `openLastOrPreferredTab`, `openNotchFromMediaPill`, reset 5 menit, antrean/auto-dismiss notifikasi, fullscreen/compact, dan DropShelf).

3. `src/components/ui/NotchEars.tsx`: Pemeriksaan komponen legacy ear geometry dan penggunaannya di codebase.
4. `src/components/ui/NotchNotifications.tsx`: `UniformHudPill`, `AutoLayoutNotifCard`, `TodoDeadlineAlertCard`, `TodoIdleCountdownPill`, `PomodoroIdlePill`, `PomodoroCompleteAlertCard`, dan `parseNotifContent`.
5. `src/components/ui/PanelNavHeader.tsx`: `PanelNavHeader`, `PanelPageDots`, dan `PanelFrame` (gestur wheel/pan swipe, status bar, tombol navigasi, keyboard/fokus).
6. `src/components/ui/ControlCenterPanel.tsx`: Tile Wi-Fi, Mode, Bluetooth, Hotspot, portal Mode Dropdown, Power Menu, slider kecerahan & volume, aksesibilitas keyboard.
7. `src/components/ui/control-center/WifiSubmenu.tsx` & `src/components/ui/control-center/BluetoothSubmenu.tsx`: Loading/error state, koneksi jaringan terbuka & berpassword, input password, timer cleanup, dan navigasi keyboard.
8. `src/components/ui/AudioOutputPanel.tsx` & `src/components/ui/VolumeMixerPanel.tsx`: Polling CoreAudio endpoints & sessions, drag slider, throttle timer cleanup, state kosong/error, dan aksesibilitas keyboard.
9. `src/components/ui/SystemMonitorPanel.tsx`: Penanganan metrik kosong/offline, grafik sparkline, dan aksesibilitas kartu ringkasan.
10. `src/components/ui/IdleLayoutSetting.tsx` & `src/components/ui/IdleMascot.tsx`: Pengukuran lebar slot idle, fallback warna teks kustom, dan siklus timer animasi maskot.
11. Backend Rust terkait kontrol cepat: `src-tauri/src/audio_endpoints.rs`, `src-tauri/src/connectivity.rs`, `src-tauri/src/system_quick_state.rs`, dan `src-tauri/src/accessibility_toggles.rs`.
12. Pengujian empiris terisolasi via Node.js (`tests/bug-hunt/T05_verify.mjs`) menggunakan TypeScript transpiler dan `react-dom/client` (React 19.1.0) terhadap komponen UI asli di atas.

2. `cargo test` / `cargo check` dan `npm run build` tidak dijalankan sesuai batasan tugas; modul Rust (`audio_endpoints.rs`, `connectivity.rs`, `system_quick_state.rs`, `accessibility_toggles.rs`) dan alur penuh `App.tsx` dianalisis langsung dari pembacaan kode sumber.

- **Lokasi**: `src/App.tsx:1753-1754` (berinteraksi dengan `src/App.tsx:1872, 1945-1955, 2070, 2274-2278, 2638, 4003, 5705, 6489, 6695`)
