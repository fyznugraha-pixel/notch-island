- **Langkah Reproduksi**:
  1. Aktifkan navbar (yang memuat `SystemNavbarModule` dan `NetNavbarModule` via `useSharedSystemMetrics()`), atau buka jendela `settings` ke `SystemMonitorPanel`. Setiap jendela WebView2 memiliki instance JS terpisah dan memanggil `invoke("subscribe_system_metrics", { topic: "metrics" })`, menaikkan `subscriptions["metrics"]` di `SharedSampler`.

- **Hasil Sebenarnya**:
  1. `win.destroy()` mematikan proses/runtime WebView2 secara instan sebelum cleanup `useEffect` di frontend sempat menyelesaikan `await invoke("unsubscribe_system_metrics", { topic: "metrics" })`.
