### T11-01
- **ID**: `T11-01`
- **Judul**: Pengiriman otomatis riwayat clipboard, catatan, to-do, nama file, dan lokasi ke AI/proxy di setiap chat tanpa persetujuan pengguna
- **Lokasi**: `src/services/aiNotchTools.ts:63-255`, `src/services/aiNotchTools.ts:260-327`, `src/services/aiChatService.ts:822-833`
- **Kategori**: Privasi / Data Keluar
- **Keparahan**: `KRITIS`
- **Frekuensi**: `Selalu`
- **Status Verifikasi**: `TERBUKTI LEWAT UJI` `[BELUM DIVERIFIKASI DI DESKTOP ASLI]`
- **Langkah Reproduksi**:
  1. Simpan teks sensitif di riwayat clipboard (`localStorage` `island_clipboard_history`), catatan di Mini Note, tugas di To-Do List, dan pengaturan jadwal sholat.
  2. Buka AI Chat atau Quick AI (termasuk saat menggunakan mode `gili-free` proxy eksternal).
  3. Kirim pesan singkat biasa tanpa melampirkan clipboard atau catatan apa pun (misalnya `"Halo"`).
  4. Amati `systemInstruction` yang dibentuk oleh `streamChatCompletion` di `src/services/aiChatService.ts:822-833`.
- **Hasil Sebenarnya**:
  Setiap permintaan chat selalu memanggil `getNotchSystemInstruction()` -> `getNotchRealtimeContext()`, yang diam-diam membaca dan menyertakan: 3 entri teks clipboard terbaru (hingga 80 karakter masing-masing), 5 catatan Mini Note (judul + isi hingga 120 karakter), hingga 10 tugas To-Do aktif beserta tenggat waktu, 5 nama file di Drop Shelf, nama lokasi jadwal sholat (`schedule.locationName`), serta judul/artis musik yang diputar, lalu mengirimkannya dalam payload permintaan ke penyedia API eksternal atau proxy `gili-free`.
- **Hasil yang Diharapkan**:
  Data pribadi seperti riwayat clipboard, catatan, tugas, file, dan lokasi pengguna tidak boleh dikirim keluar secara otomatis di belakang layar; konteks tersebut hanya boleh disertakan bila pengguna secara eksplisit memilih melampirkannya atau mengaktifkan izin integrasi konteks per kategori.
- **Bukti**:
  `TERBUKTI LEWAT UJI` (`tests/bug-hunt/T11_verify.mjs` -> `TEST-07`):
  ```text
  [PROVEN] TEST-07 - ... clipboardInjectedInSystemCtx=true
  ```
  Cuplikan kode (`src/services/aiNotchTools.ts:233-250`):
  ```ts
  const rawClip = localStorage.getItem("island_clipboard_history");
  if (rawClip) {
    const parsedClip = JSON.parse(rawClip);
    if (Array.isArray(parsedClip) && parsedClip.length > 0) {
      const recentTexts = parsedClip
        .filter((c: any) => c.type !== "image" && c.text)
        .slice(0, 3)
        .map((c: any, i: number) => `#${i + 1}: "${String(c.text).replace(/\s+/g, " ").trim().slice(0, 80)}"`)
        .join(" | ");
  ```
  Dan pemanggilannya pada setiap request (`src/services/aiChatService.ts:822, 833`):
  ```ts
  const notchInstruction = getNotchSystemInstruction();
  ...
  ${notchInstruction}`;
  ```
- **Dugaan Akar Masalah**:
  `getNotchRealtimeContext()` didesain menyuntikkan seluruh ringkasan status lokal secara tanpa syarat ke `systemInstruction` agar model selalu memiliki konteks, tanpa mekanisme opt-in/privasi maupun pengecualian data sensitif (clipboard dan catatan).
- **Usulan Perbaikan**:
  Pisahkan konteks non-sensitif (waktu lokal/status timer opsional) dari data pribadi (clipboard, catatan, to-do, file, lokasi); wajibkan persetujuan/toggle eksplisit pengguna (default nonaktif untuk clipboard & catatan), atau gunakan model tool-calling yang hanya mengambil data tertentu saat diminta eksplisit oleh pengguna di sesi tersebut, serta nonaktifkan konteks lokal otomatis saat memakai `gili-free`.
- **Risiko Perbaikan**:
  Perintah suara/teks seperti "buka catatan tadi" atau "tandai tugas barusan" akan membutuhkan satu langkah pengambilan konteks eksplisit atau toggle opt-in di pengaturan AI.

### T11-02
- **ID**: `T11-02`

- **Langkah Reproduksi**:
  1.   2. Panggil `executeGiliAction` dengan `params: null`, atau `params: { text: 123 }`, atau `params: { query: ["a"] }`, atau `params: { amountMl: -500 }`.
  3. Amati eksekusi di `aiNotchTools.ts` dan penanganannya di `aiBackgroundStreamService.ts:384-441`.
- **Hasil Sebenarnya**:
  1. Setiap blok ```` ```gili_action ````, ```` ```gili-action ````, maupun ```` ```action ```` (tag umum markdown!) langsung dihapus dari teks tampilan dan dieksekusi otomatis tanpa konfirmasi pengguna, termasuk aksi destruktif (`delete_todo`, `delete_note`, `update_note` via `.includes(query)`) dan kontrol OS melalui Tauri IPC (`set_master_volume`, `set_brightness`, `smtc_action`).

  3. `log_water` menerima `amountMl: -500` atau `Infinity`, dan `control_pomodoro` menerima `minutes: Infinity`.
- **Hasil yang Diharapkan**:
  1. Hanya tag khusus (bukan ```` ```action ```` umum) yang dikenali; aksi destruktif (`delete_todo`, `delete_note`, `update_note`) dan kontrol sistem OS (`set_system_control`) harus meminta konfirmasi klik pengguna di UI (atau tombol "Jalankan Aksi") sebelum dieksekusi.
  2. Semua field `params` divalidasi tipenya (`typeof === "string"`, plain object non-null, `Number.isFinite` dengan batas rentang wajar) di dalam `executeGiliAction` tanpa pernah melempar `TypeError`.

- **Usulan Perbaikan**:
