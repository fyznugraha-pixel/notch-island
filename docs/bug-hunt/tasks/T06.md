### T06-01
- **ID**: `T06-01`
- **Judul**: Listener `Escape` global di `TaskbarFlyoutApp` menutup seluruh flyout sebelum submenu `QuickSettingsView` menanganinya
- **Lokasi**: `src/components/taskbarFlyout/TaskbarFlyoutApp.tsx:402-407`, `src/components/taskbarFlyout/views/QuickSettingsView.tsx:396-410`

  1. Buka flyout Quick Settings dari taskbar dock.
  2. Klik ikon panah submenu pada tile Wi-Fi, Bluetooth, atau Aksesibilitas sehingga `activeSubmenu` bernilai `"wifi"` / `"bluetooth"` / `"accessibility"`.
  3. Tekan tombol `Escape` pada keyboard.
- **Hasil Sebenarnya**: Seluruh jendela flyout langsung tertutup karena listener `keydown` pada `TaskbarFlyoutApp` dijalankan lebih dahulu daripada listener `keydown` milik `QuickSettingsView` dan langsung memanggil `invoke("close_taskbar_flyout")`.
- **Hasil yang Diharapkan**: Saat berada di dalam submenu (`activeSubmenu !== null`), menekan `Escape` seharusnya hanya menutup submenu dan mengembalikan pengguna ke tampilan utama Quick Settings; menekan `Escape` kedua kalinya di tampilan utama barulah menutup flyout.
- **Bukti**:
  `src/components/taskbarFlyout/TaskbarFlyoutApp.tsx:402-407`:
  ```ts

      if (e.key === "Escape") {
        e.preventDefault();

        return;
      }
  ```
  `src/components/taskbarFlyout/views/QuickSettingsView.tsx:396-410`:
  ```ts

      if (e.key === "Escape") {
        if (activeSubmenu) {
          e.preventDefault();
          setActiveSubmenu(null);
        } else if (onClose) {
          e.preventDefault();
  ```

- **Usulan Perbaikan**: Ubah listener `Escape` di `QuickSettingsView` (dan komponen anak lain yang memiliki sub-dialog seperti input password Wi-Fi atau power menu Start) untuk mendaftar pada fase capture (`window.addEventListener("keydown", handleKeyDown, true)`) serta memanggil `e.stopImmediatePropagation()` saat menutup submenu, atau lewati `close_taskbar_flyout` di `TaskbarFlyoutApp` apabila `e.defaultPrevented` bernilai `true`.
- **Risiko Perbaikan**: Rendah; perlu memastikan komponen anak hanya memanggil `stopImmediatePropagation()` saat benar-benar menangani `Escape` agar Escape tetap menutup flyout di level utama.
