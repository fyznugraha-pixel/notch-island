### 1.3 Bagian yang Tidak Sempat / Tidak Dapat Diperiksa di Lingkungan Headless
Sesuai aturan ketidakpastian dan larangan mengarang bukti, area berikut **tidak diuji secara interaktif pada sesi desktop fisik pengguna** sehingga seluruh temuan terkait diberi penanda `[BELUM DIVERIFIKASI DI DESKTOP ASLI]`:
1. **Perilaku Visual DWM & Multi-Monitor Fisik**: Transisi visual shader Gaussian blur `Windows.UI.Composition` saat mencabut/memasang kabel monitor HDMI/DisplayPort secara langsung atau mengubah orientasi layar (landscape ke portrait).
2. **Transisi Daya Perangkat Keras (ACPI Sleep S3 / Modern Standby S0ix)**: Perilaku nyata driver GPU dan DWM ketika laptop ditutup (sleep) lalu dibuka kembali (wake) atau saat baterai benar-benar menyentuh ambang Battery Saver Windows.
3. **Pembayaran & Lisensi Microsoft Store Live**: Alur pembelian add-on `StoreContext::GetDefault()` terhadap server produksi Microsoft Store karena membutuhkan paket MSIX yang terinstal dari Store dengan akun Microsoft aktif.
4. **Interaksi Layar Sentuh & Pembaca Layar Fisik (NVDA / Narrator)**: Pengujian pembacaan pohon aksesibilitas dilakukan melalui audit DOM/ARIA dan perhitungan kontras WCAG terprogram (`T14_verify.mjs`), bukan rekaman suara NVDA langsung.
5. **Kompilasi Penuh `cargo build` / `MakeAppx.exe`**: Tidak dijalankan selama sesi bug-hunt untuk mematuhi aturan penghindaran konflik direktori build dan menjaga pohon kerja tetap bersih.

## 3. Pengelompokan Akar Masalah Utama (Root-Cause Clusters)

Banyak bug yang ditemukan di modul berbeda sesungguhnya lahir dari **12 akar masalah arsitektural yang sama**:

1. **Klaster RC-01: Pemotongan String Byte `&s[..N]` di Rust + `panic = "abort"` di Produksi**
   - *Temuan terkait*: `T01-01`, `T01-02`, `T10-16`.
   - *Akar masalah*: `src-tauri/Cargo.toml:52` menyetel `panic = "abort"` pada profil rilis. Sementara itu, kode Rust di `tray_apps.rs:321`, `lib.rs:956`, `lib.rs:2125`, dan `lyrics_share.rs:133` memotong string menggunakan indeks byte mentah (`&text[..40]`, `&err_str[..120]`, `&s[..16]`). Begitu batas byte jatuh di tengah karakter UTF-8 multi-byte (emoji, huruf Jepang/Korea/Mandarin/Arab, atau tanda baca Unicode seperti `…` dan `-`), Rust langsung panic dan meng-abort seluruh proses aplikasi tanpa sempat menjalankan `restore_taskbar_on_exit()`.
2. **Klaster RC-02: Modifikasi State Shell/OS Windows Tanpa Watchdog Eksternal & Tanpa Pemulihan Menyeluruh**
   - *Temuan terkait*: `T03-05`, `T03-08`, `T03-11`, `T04-02`, `T12-02`, `T03-01`, `T03-02`, `T03-17`.
